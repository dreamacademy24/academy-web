# 화상영어 전용 신청서 booking3

신청: `/booking3` · 직원 접수: `/admin/online-class?tab=applications`

## 손님
학생·보호자 정보를 입력하고 주 2/3/5회, 1/2/3/6개월, 평일 요일별 희망 시간을 선택한다. 현재 운영 시간인 한국 14:00–21:30 시작, 25분 수업을 적용한다. 1개월은 4주이며 월 요금은 각각 72,000/105,600/160,000원이다. 3개월은 2주, 6개월은 4주 추가한다. 기본 회차와 혜택 회차, 금액을 분리 표시한다. 소개 혜택은 직원 확인 후 별도 반영한다.

접수 완료 후 `홈페이지와 앱/화상영어_수업_안내_하우스스타일.png` 원본(2026-09-02)을 자동으로 연다. 다시 보기·원본 저장도 지원한다. 접수 자체로 결제나 시간 배정을 확정하지 않는다.

## 직원
화상영어 → 화상영어 신청서에서 연락처·요청·금액을 확인한다. 입금과 일정 확인 후 시작일을 지정하여 수강권·앱 계정 발급을 누른다. 새 계정은 아이디·임시 비밀번호를 발급하며, 실제 로그인으로 확인한 기존 계정은 비밀번호 변경 없이 연결한다. 수강권 상세에서 담당 선생님을 배정한다. 계정 안내 문구를 복사하여 확인한 보호자에게 전달한다. 메시지를 자동 발송하지 않는다.

## 데이터 및 실패 처리
- 공개 신청 API는 계정·수강권을 발급하지 않고 접수만 저장한다. 가격·회차는 서버에서 재계산한다.
- 신청 키에 따른 중복 접수 방지, IP 기준 접수 제한, 직원 인증 후 발급, 처리 잠금 및 재시도를 적용한다.
- 계정 생성 중 연결이 끊겨도 같은 신청서의 계정·암호를 복구한다. 수강권·출석부·발급 상태는 DB 트랜잭션으로 함께 확정한다.
- 임시 비밀번호는 서버 키로 암호화하여 보관하며 직원 발급 화면에서만 복호화한다. 운영 키 교체 시 기존 암호의 이관이 필요하다.
- 새 신청서·프로필·수강권·출석부는 익명 사용자에게 노출하지 않는다. 앱 조회·취소·변경 API는 본인 인증을 확인한다. 기존 예약·수강생 기록을 변경하는 마이그레이션은 없다.
- 휴일, 기존 계정의 연결된 연수 체류 기간, 현재 스케줄 계산 규칙을 적용한다.

## 검증
- 단위/API 검증 12개, 기존 출석부 회차 회귀 검증 11개 통과.
- 실제 Supabase/Auth 통합 검증 9개: 중복 접수, 동시 발급, 재발급, 42회 일정, 앱 로그인, 익명 접근 차단, 본인 회차 변경 차단, API 본인 확인, 기존 계정 재사용. 생성한 테스트 계정·신청·출석부는 정확한 ID로 정리한다.
- 브라우저에서 접수 완료 → 최신 원본 안내 팝업을 확인했다.
- TypeScript 검사 통과. 배포 후 실제 주소와 접수 API를 추가 확인한다.
- Supabase 보안 검사에서 신규 접수 테이블의 정책 없음 안내는 서비스 역할 전용 설계에 따른다. 기존 unrelated RLS 미설정 항목은 이번 기능 범위 밖이다. 참고: https://supabase.com/docs/guides/database/database-linter

배포 확인 후 `[새 기능 안내]` 일반 공지를 1회 게시한다. 기존 안내서 및 읽음·업무 완료 상태는 유지한다.
