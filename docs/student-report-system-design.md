# 학생 리포트와 연수 이력 연결 — 양식 검토

상태: 사용자 제공 PDF 2페이지를 텍스트와 렌더링으로 검토한 설계 기록. 서비스 연동 또는 학생 데이터 등록은 아직 수행하지 않았다. 원본 PDF는 수정하지 않았다.

## 확인된 양식

- 공통 머리말: Student Name, Date, Duration, Level, Score, Book Level.
- 1페이지 Student Report / Student Progress Report: Week 1~8, Speaking skill, Listening comprehension, Reading comprehension, Writing skill의 주차별 그래프. 최종 영역 점수는 각 100점, 총점 400점. Scoring Interpretation 표 포함.
- 2페이지 Teacher's Feedback: Speaking, Listening, Reading, Writing 영역별 서술 의견.
- 일반 영어 수준(Level)과 교재 단계(Book Level)는 별개 항목이다. 서로 자동 치환하지 않는다.

## 데이터 구조 원칙

1. 공통 학생: 고유 학생 ID, 보호자/형제자매 연결. 이름만으로 기존 학생을 자동 병합하지 않는다.
2. 방문 이력: 학생 ID 아래 연수 시작·종료일, 방문 회차, 담당 한국인 직원, 담당 교사와 배정 기간.
3. 학습 이력: 해당 방문 안의 레벨·교재·판본·실제 수업 범위와 적용 날짜. 새 방문이나 레벨 변경 시 과거 값을 덮어쓰지 않는다.
4. 평가: 방문 ID, 평가 날짜/주차, 4영역 점수, 평가자, 평가 기준 버전. 예시가 8주일 뿐 방문 기간을 8주로 제한하지 않는다. 미평가와 0점을 구분한다.
5. 교사 의견: 방문·평가·영역 연결, 작성자/작성 시각, 강점·보완점·권장 복습. 담당 교사가 여럿이면 각각의 기록을 보존한다. 기존 자유 서술도 지원한다.
6. 발행 리포트: 해당 시점의 기간·수준·교재·점수·의견을 스냅샷으로 보존. 초안/검토/발행 상태와 수정 버전 관리. 원본 PDF 첨부 가능. 개인정보와 실제 학생 리포트 본문을 소스 코드에 저장하지 않는다.
7. 사후 케어: 해당 방문 및 교재 단원에 복습 과제, 녹음·쓰기 제출, 담당 교사의 리뷰, 화상 리뷰와 후속 과제를 연결한다.

## 공유 화면

- 한국인 홈과 현지 교사 홈은 동일한 학생/방문 ID를 사용한다. 기존 데이터 구조 확인 후 연결하며 별도 학생 명부를 중복 생성하지 않는다.
- 현지 교사는 배정 학생의 수업 전 참고사항, 이전 방문 요약, 현재 수업 이력과 제출물을 확인한다.
- 내부 지도 메모와 보호자 공개 리포트를 구분하고 담당자 권한을 적용한다.
- 보호자 학습모드에서는 아이 선택 후 본인 자녀의 발행 리포트와 복습만 표시한다.
- 공식 교재 단계명을 사용하고 BR 계열 내부 대응값은 앱/책/배포 파일에 노출하지 않는다.

## 원본에서 발견한 확인 사항

- 최종 영역 점수 30 + 39 + 41 + 42 = 152이지만 머리말과 총점에는 155로 표시되어 있다. 자동 합산 및 발행 전 일치 검증이 필요하다. 원본 숫자를 임의 수정하거나 실학생 성적으로 등록하지 않는다.
- Scoring Interpretation에 105–135 다음 145–165가 있어 135 초과 145 미만 구간이 비어 있다. 여러 구간의 끝과 시작 숫자도 겹친다. 경계 포함 규칙, 0점 처리와 누락 구간은 학원 기준 확인 전 자동 등급 판정에 사용하지 않는다.
- Level 표기와 Scoring Interpretation의 Performance Band는 다른 체계일 수 있다. 점수만으로 Level 또는 Book Level을 추정하지 않는다.
- PDF에는 평가자/담당 교사 표기가 보이지 않는다. 시스템에서는 작성자와 담당 교사를 별도로 기록한다.

## 구현 순서

기존 한국인 홈 데이터 및 권한 확인 → 공통 학생과 방문 이력 연결 → 현지 교사 담당 학생 화면 → 주차 평가/교사 의견 → 검토·발행 및 PDF 출력 → 귀국 후 복습·교사 리뷰.
