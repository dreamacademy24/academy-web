# 연수 전후 화상영어 배분 / 직원 댓글 사진

## 반영 범위

- 연수 1주당 3회, 학생별 여러 예약 합산. 주 2·3·5회 선택과 제공 회차를 분리한다.
- 관리자 수동 총 회차 조정은 사유를 남긴다. 전후 회차·희망 시작일·요일별 시간을 따로 설정한다.
- 부모 앱 신청, 관리자 상세, 출석부, 앱 조회, 안내 멘트를 같은 전후 계획에 연결한다.
- 기존 출석·취소·보강, 과거 예정 및 기록 있는 회차는 보존한다. 모호한 사용 회차나 기간 초과는 저장을 막고 이유를 표시한다.
- 예약별 회차 중복 사용을 DB에서 차단한다. 저장은 잠금·버전 검사·단일 트랜잭션으로 처리한다.
- 기존 단일 일정 수정 경로로 전후 계획을 덮어쓸 수 없다. 부모의 이미 접수된 전후 배분 변경은 직원에게 요청한다.
- 댓글은 사진만으로도 등록 가능하며 10장까지 지원한다. 선택 사진 미리보기·제거, 수정 시 추가·제거, 확대 보기, 작성자 삭제를 지원한다.
- 업로드는 실제 직원 세션과 업무 접근 권한을 확인한다. 이미지 형식/바이트/크기 및 작성자·업무별 저장 경로를 검증한다.
- 사용자 입력과 업로드 성공분은 저장 실패 시 유지한다. 기존 업무·공지 읽음 상태는 변경하지 않는다.

## 검증

- TypeScript 검사 통과.
- 패키지 규칙 14건, booking3 기존 규칙 12건, 직원 댓글·업무 회귀 93건 통과.
- 실제 Auth·DB·신청 HTTP 11건: 12회 생성, 9/3 구분, 재시도·중복 차단, 이력 보존, 오래된 저장 거부, 보강 기간 검증.
- 실제 직원 로그인·이미지 저장소·댓글 HTTP: 사진 전용 등록, 재시도, 사진 수정·추가·제거·삭제, 익명 거부 통과.
- Chrome 브라우저: 다중 예약 합산, 주 2회에도 총 회차 유지, 전부 전/후 및 9/3 배분, 신청 후 기존 수업 안내 팝업.
- Chrome 브라우저: 여러 사진 업로드·제거·저장 실패 유지·사진 전용 등록·확대·수정·삭제.
- 테스트는 별도 임시 가족/비공개 업무/직원 계정을 사용하고 정확한 ID로 삭제한다. 운영 학생의 수강 내역은 임의로 바꾸지 않는다.

## 공지

배포와 라이브 검증 후 기존 공지 중복을 확인하고 일반 `[새 기능 안내]` 공지로 안내한다. 기존 사용 안내서를 다시 게시하거나 읽음 확인 업무를 만들지 않는다. 공지용 이미지는 가상 학생·직원으로 촬영했다.
