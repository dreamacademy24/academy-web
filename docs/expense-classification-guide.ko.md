# 지출 입력·분류 기준 안내

이 안내의 예시는 과거 표본에서 분류 기준을 설명하기 위한 것으로, 거래 발생·지급 확정이나 공식 회계정책 승인을 뜻하지 않습니다.

## 접근 권한

- 아비·벨라: 자기 지출 입력·자기 제출 내역·검토 상태만 조회
- 대표: 전체 원장·기존 개인 장부·검토 및 승인·통합 손익 조회
- 그 외 계정: 입력 API와 원장 API 접근 불가
- 기존 원장 비밀번호만으로 접근하는 우회 경로는 제거하고 서명된 대표 세션으로 확인

## 공통 기준

- 예시는 분류 안내용이며 실제 거래 등록·발생·지급 확정이 아닙니다.
- 돈을 보낸 곳이 아니라 실제 혜택을 받은 사업장을 고릅니다. 공통 비용은 근거 없이 배분하지 않습니다.
- 003 잉크는 사무·인쇄, 프린터 수리는 유지보수, 새 프린터는 비품 구입으로 구분합니다.
- 요리 수업 재료는 교육·활동비, 학생 간식은 학생 식음료, 아떼 간식·회사 승인 쌀 지원은 복리후생입니다. Teacher 같은 수취인 이름만으로 급여라 판단하지 않습니다.
- 9월에 낸 6월분 관리비처럼 지급일과 해당 월이 다를 수 있습니다. 두 필드를 따로 기록합니다.
- Converge 원장과 영수증의 금액이 달랐던 사례처럼 증빙이 충돌하면 금액 확인 필요로 제출합니다. 어느 쪽도 자동 선택하지 않습니다.
- 한 영수증에 여러 하우스가 섞이면 원금은 한 번만 기록합니다. 확인된 하우스별 금액만 입력하고, 미확정이면 복수 하우스·미배분으로 남깁니다.
- 아카데미→드림하우스 예산 전달, C.A., 업무 선급금은 그 자체로 운영비가 아닙니다. 실제 사용 정산과 중복하지 않습니다.
- 튜터 급여+교통비, 여러 품목 혼합 거래는 항목별 금액 확인 전 임의 분할하지 않습니다.
- 모리 식대는 발생 비용과 지급·정산을 구분합니다. 이미 발생 처리한 식대를 지급할 때 다시 비용으로 더하지 않습니다.
- 학생 SSP·비자 대행금은 회사 인허가 비용과 구분하고, 대출원금은 이자·수수료와 구분합니다.
- 원장과 영수증·수정 전후 사진은 같은 거래일 수 있습니다. VAT 포함 금액의 세금을 다시 더하지 않습니다.
- 전일 이월·잔액·권종 메모와 기존 물품의 방 이동은 새 지출이 아닙니다.
- 고가 비품·장비의 비용/자산 처리는 대표 확인이 필요합니다. 판단 전에는 손익에 반영하지 않습니다.
- 입력은 아비·벨라만 가능합니다. 자기 제출 건만 조회하며 전체 원장·서로의 내역·잔액·손익은 대표만 조회합니다.

  - 분류 예시: 회사 인허가 청구·승인·영수증 확인 후 분류하는 예시

- **대출이자·금융수수료**: 이자·수수료가 분명히 확인된 부분만 기록합니다. 대출원금이나 혼합 납부액을 추정 분할하지 마세요.
  - 분류 예시: 상환 내역에서 원금과 별도로 확인되는 업무 이자·수수료
