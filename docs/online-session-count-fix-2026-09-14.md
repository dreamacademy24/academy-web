# 화상영어 출석부 회차·시작일 수정

## 원인

기존 수강권의 총 회차가 출석/취소/보강 이력보다 작으면 PATCH의 needed > 0 분기를 건너뛰고 ok:true, sessions_regenerated:0을 반환했다. 수강권 시작일/총 회차는 먼저 저장되어 출석부와 불일치했다. 복구 버튼은 폼 입력을 보내지 않아 미저장 변경을 사용하지 않았다. 기존 used_sessions가 이력 행 수보다 큰 데이터에서는 이력 행 수만 차감해 잔여 수업보다 많이 생성했다.

## 수정

- 총 회차 변경 및 날짜 복구 전에 현재 이력/사용 횟수를 검사한다. 불가능한 축소 또는 남은 회차 없이 예정 수업이 있는 경우 409와 구체적 사유를 반환하며 변경을 시작하지 않는다.
- 복구 계산은 이력 행 수와 저장된 사용 횟수 중 큰 값을 차감한다. 사용 횟수/출석 상태를 임의로 변경하지 않는다.
- 복구 버튼은 현재 폼을 저장하는 경로를 공유한다. 폼의 시작일/요일별 시간/회차를 함께 전달한다.
- 실패 사유를 사라지는 토스트 대신 지속적으로 표시한다. 입력값을 보존하고, 요청 중 중복 클릭을 막는다.
- 기존 이력보다 총 회차가 작은 화면에 안내를 표시한다. 총 회차는 같은 수강권의 기존 사용분을 포함하는 값임을 안내한다.

## 검증

scripts/test-online-session-count.cjs: 11개 통과. 무변경 사전 차단, 유효한 기존 수강권 일정 수정, 저장된 사용 횟수 보존, 신규 15회 날짜, 미래 보강 보존, 미저장 폼 전달, 인증/조회 실패를 검증했다. TypeScript 전체 검사 통과.

사용자는 신규 수강권을 변경하지 말라고 지정했다. 기존/신규 수강권의 운영 DB 행은 이 작업에서 수정하지 않았다. 이미 잘못 저장된 기존 수강권의 총 회차를 임의로 추정해 복원하지 않는다. 이 수정은 일관되지 않은 회차를 성공으로 보고하지 않도록 하고, 유효한 회차의 변경을 정상 계산한다.

배포/운영 검증 결과는 확인 후 추가한다.
