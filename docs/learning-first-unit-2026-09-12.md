# BR40 학습 앱 첫 단원 — My Tree House

사용자가 승인한 DSL-F2 (BR40) Week 1 새 교재의 Day 1을 구현했다. 교재 내용이 기준이며, 앱 활동과 세 장면 삽화는 이를 연결한다. 다른 직원 업무의 진행 중 변경과 충돌하지 않도록 `codex/learning-first-unit` 브랜치의 독립 작업 폴더에서 작업했다.

## 실행

- 작업 폴더: `C:/Users/desko/academy-web/.release/learning-app`
- `npm run dev -- --port 3108`
- `/dream-app`: 기존 게스트 포털과 학습 입구
- `/learn`: 학습 홈, 보호자 안내
- `/learn/tree-house`: 나무집 탐험부터 모험 기록까지

## 구현된 수업

1. 나무집 그림의 나무, 집, 사다리, 문, 창문을 터치하여 단어·뜻·설명·소리 확인.
2. tree / house / climb / ladder / knock / door / jungle / window의 그림 설명, 듣기, 그림 찾기, 직접 입력과 글자 조합 스펠링, 손글씨, 단어·문장 녹음.
3. 승인된 A Place to Read 전체 이야기, 세 장면의 그림, 전체·장면·단어 듣기, 두 가지 내용 확인 문제와 문장 녹음.
4. 문장 틀과 단어를 사용한 내 문장, 손글씨/그림, 내 이야기 녹음.
5. 실제 수행한 활동별 기록과 재학습 진입. 글자 버튼 도움과 직접 입력 성공을 구분.

## 데이터와 실제 동작 범위

- IndexedDB에 학습 상태, 손글씨, 입력 문장과 녹음 Blob을 저장. 새로 열어 이어하기 가능. 다른 기기 동기화·학생 계정·선생님 제출은 아직 연결되지 않았다.
- 기기 영어 TTS를 사용한다. 녹음 파일은 다시 듣기·다운로드 가능. 발음 점수나 손글씨 인식 결과를 가짜로 표시하지 않는다.
- 녹음 30초 제한, 권한 거절, 늦게 도착한 마이크 응답 취소, 화면 숨김 시 중단, 트랙 정리, 저장 실패 안내를 처리했다.
- 해당 학습 경로는 기존 설치 배너와 서비스워커의 자동 새로고침을 실행하지 않는다.
- 서버 배포 및 앱스토어 배포는 하지 않은 로컬 구현이다. 정식 판매 전 계정·서버 저장·실기기 음성 확인과 정식 내레이션 준비가 남아 있다.

## 검증

- Next.js 프로덕션 빌드 및 TypeScript 검사 통과.
- 새 학습 경로/컴포넌트 ESLint 오류 0개. 비동기 취소용 ref cleanup 관련 경고 2개.
- Playwright + 설치된 Chrome: PC/390px 모바일 화면, 이미지 로드, 8단어 전환, 그림·스펠링 정답/오답, 글자 버튼, 손글씨 저장, 녹음/새로고침 복원, 스토리 문제, 문장 만들기와 재진입, 마이크 거절·늦은 권한 응답 취소 확인. 페이지 실행 오류 0개.
- 녹음 테스트는 브라우저의 가상 마이크를 사용했다. 사람의 실제 목소리와 iOS/Android 실기기 음질 검증을 대체하지 않는다.
- 테스트 코드: `scripts/verify-learning.cjs`. 화면 증거: `artifacts/learning/`.
