## 소개 영상 적용 준비

- 승인한 합성 목소리를 참조로 Base 1.7B를 사용해 `artifacts/free-voice/intro/intro-01.wav`와 `intro-02.wav` 생성 완료. 한국어 인사와 Hello, 이야기 안내 대사다.
- 세 번째 요청의 공개 API는 원인이 없는 오류를 반환했다. 같은 공개 서비스·동일 비로그인 상태에서 단 한 번 확인한 결과 `ZeroGPU quota exceeded`, 요청 90초 / 잔여 0초가 확인됐다. 확인 뒤 추가 비로그인 생성 요청은 중단했다. 한도 우회나 유료 전환은 하지 않는다.
- 사용자가 회원가입·이메일 인증과 참조 WAV 업로드를 완료했다. 로그인된 무료 계정의 공식 데모 UI에서 03~05를 각 한 번 생성해 모두 성공했고 `scripts/save-dreamy-browser-voice.mjs`로 관찰한 결과 다운로드 링크의 WAV와 출처 기록을 저장했다. 추가 결제·충전·유료 생성은 없었다.
- 세 번째 대사는 Auto, 네 번째와 다섯 번째는 Korean, 모델 1.7B, x-vector only 해제. 다섯 요청의 대사와 참조 SHA를 기존 타임라인과 대조해 일치했다.
- 유료 잔액 자동 사용이 가능한 계정인 경우 무료 한도 내 작업인지 먼저 확인한다. 토큰·비밀번호를 대화에 요청하지 않는다.
- `scripts/assemble-dreamy-qwen-intro.py --verify-requests`로 다섯 WAV를 설치했다. 원본 24kHz mono PCM16과 말속도·피치를 유지하고 앞뒤 무음만 정리했으며, 첫 음성 시작은 영상 0.04초 지점이다. 타임라인은 17.727458초, 한국어 VTT도 실측 길이에 맞췄다.
- 기존 WAV·JSON·VTT는 `artifacts/free-voice/previous-intro`, 기존 MP4는 `artifacts/free-voice/previous-video`에 원본 해시와 함께 보존했다. 설치 기록은 `artifacts/free-voice/intro-install.json`이다. `--check --verify-requests`는 생성이나 설치 없이 입력·출력 검증만 한다.
