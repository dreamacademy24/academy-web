# 드림이 학습 모험 — 사용자 게임 아이디어 기록

## 사용자 결정

- 기본 학습을 먼저 제공하고, 마지막 이야기 게임에서 배운 내용을 스스로 사용하는지 확인한다.
- 드림이와 목표를 달성하며 단계별로 진행하는 모험 구조로 기획한다.
- 아래 게임 예시는 사용자가 직접 제안했다. 높은 레벨에서 활용할 확장 아이디어로 보존한다. 현재 초급 단원에 모두 구현하라는 요청이 아니다.
- 다양한 게임을 단계의 학습 목표와 난이도에 맞춰 배치한다. 구체적인 레벨 배정과 진급 조건은 아직 확정하지 않았다.

## 보존할 게임 예시

| 사용자 아이디어 | 핵심 동작 | 높은 레벨 확장 시 검토할 요소 |
|---|---|---|
| 슈퍼마리오처럼 이동하며 영어로 장애물 통과 | 길을 가다가 나무가 나오면 `tree`를 외쳐야 다음으로 진행 | 그림 이름에서 설명·문장 말하기로 확장. 이동 조작 성적과 영어 성취는 분리 |
| 단어 조합으로 통과 | 흩어진 글자나 조각을 조합해 단어를 완성하면 길이 열림 | 조각 수, 방해 조각, 철자 복잡도를 단계적으로 조절 |
| 여러 단어 속 정답 찾기 | 단어들이 많이 놓인 화면에서 조건에 맞는 단어 선택 | 소리·그림·뜻·문맥 단서로 난이도 조절 |
| 단어 찾기 퍼즐 | 퍼즐 형태로 숨은 단어를 찾아 연결 | 글자판 크기와 탐색 방향을 학습 단계에 맞춰 설계 |
| 사천성처럼 흩어진 단어 조각 연결 | `app`와 `ly`처럼 따로 놓인 조각을 탁탁 연결해 완성 | 철자 조각, 음절, 접두·접미사 목적을 구분. `app + ly`는 사용자 철자 조합 예시이며 발음·형태소 분할 기준으로 자동 적용하지 않음 |

## 설계 시 유지할 조건

- 위 항목은 기획 후보이며 구현 완료 기능으로 안내하지 않는다.
- 녹음 저장만으로 발화 정답을 판정하지 않는다. 말하기로 통과시키는 게임은 음성 인식·판정 및 인식 실패 시 재시도/대체 입력을 설계해야 한다.
- 게임 확인 결과는 혼자 해결, 힌트 후 해결, 다시 연습 등으로 구분하는 방향을 검토한다.
- 학습 단계의 정식 표기는 DSL-F2, DSL-T1, DR-F1, DR-F2, DR-S, DR-T이다. 단계 순서·게임 배정은 추후 확정한다.
- BR 계열 수치는 내부 제작 대응값이다. 사용자 지시대로 앱·책·학습 결과·배포 파일명에는 노출하지 않는다. 기존 산출물의 노출 제거는 별도 점검 대상이며 이 기록만으로 완료된 것은 아니다.

### 적용 방향 제안 — 아직 구현·레벨 배정 미확정

- 기존 기본 학습 → 이야기 연습 → 마지막 게임 → 필요한 복습의 흐름과 듣기·매칭·철자·쓰기·녹음 기능을 유지한다. 별도 게임 메뉴를 늘리지 않고 단원 안의 마지막 모험으로 연결한다.
- 첫 단원 후보: 이야기에서 배운 `tree`, `house` 등을 그림과 연결하거나 철자를 완성하면 해당 사물이 나타나고, 사다리·문·램프처럼 이야기 목적에 맞는 변화가 일어난다. 실제 문항에는 승인된 교재·단원 어휘만 사용한다.
- 높은 단계 후보: 글자/단어 조합 성공으로 도구를 완성하고, 문맥에 맞는 문장을 선택해 다음 장애물을 해결하는 연속 미션. 단순한 같은 그림 합치기만으로 영어 학습이 완료되지는 않는다.
- 정답 뒤에 별개의 오락만 오래 하는 구조보다 학습에 필요한 판단이 게임 행동을 직접 일으키는 구조를 우선한다. 틀렸을 때는 짧은 힌트와 재도전, 완료 뒤에는 명확한 종료와 복습 안내를 제공한다.
- 성공 연출과 학습 기록은 분리한다. 첫 시도 정답·힌트 사용·재시도·어려웠던 단어를 기록할 후보로 삼으며, 캐릭터 강화 수치나 반사신경 점수만으로 레벨을 올리지 않는다. 향후 서버 제출·교사 리뷰 연결 전에는 교사가 확인 가능하다고 안내하지 않는다.
