Dreamy introduces listening, speaking, word play and the final mission inside that lesson. There is no separate intro landing page. Existing child ownership, assignment validation and scoped device storage remain enforced.

Reference reviewed: the user-provided Doyose screen recording, 88.872 seconds. This informed the app composition and continuity; reference footage is not bundled with the app.
