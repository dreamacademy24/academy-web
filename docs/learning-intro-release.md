# 드림이 공통 소개와 아이별 학습 시작 — 2026-09-13

학습 모드의 첫 경험을 망고 드림이가 설명하는 공통 소개로 바꾼다. 이야기를 보고, 듣고 말하고, 써보고 마지막 게임으로 확인하는 방법을 약18초 영상으로 안내한 뒤 아이별 배정 교재를 연다. 특정 책을 모든 아이에게 자동으로 배정하지 않는다.

- 실제 Three.js 메시로 만든 망고·고래상어, 카메라·조명·표정·지느러미·손동작. 로컬 렌더 MP4/H264/AAC, 승인한 Qwen 합성 샘플을 참조한 다섯 안내 대사, 한국어 VTT. Qwen 공식 무료 데모로 제작했고 원본 속도·피치 유지, 앞뒤 무음만 정리했다. 외부 유료 생성 서비스 호출 없음. 세부 출처·백업은 `free-dreamy-voice-preview.md` 참조. 운영 배포 전.
- 소개 재생·멈춤·다시보기·건너뛰기·재생 오류 복구. 첫 소개를 본 기기는 다음부터 학습 홈으로 가며 하단에서 다시 소개를 볼 수 있다.
- 보호자 로그인 → 본인 예약의 현재 학생 원본과 검증된 학생·방문 연결 → 아이 선택 → 해당 방문의 공식 레벨·교재. 현재 공개 단원은 DSL-F2 / My Tree House 하나다. 미배정·미공개·조회 실패를 구분한다.
- 자녀와 방문별로 진도·글씨·녹음을 기기 안에서 분리한다. 기존 익명 체험 기록은 유지하며 아이 기록으로 자동 복사하지 않는다. 계정 로그아웃·변경·오래된 응답은 다른 아이 정보를 복원하지 않는다.
- 기존 이야기 뒤의 마지막 미션: 그림 2개 → 매칭 3쌍 → 철자 2개 → 추억책과 오답 복습. 도움을 쓴 단어는 표시한다. 기존 이야기·단어 찾기·매칭·필기·녹음 유지.
- 기존 학생관리의 케어 창 안에 접이식 ‘학습 레벨 · 교재’를 추가한다. 한국인 관리자는 배정, 배정된 현지 교사는 영문 조회. 방문별 변경을 누적하며 동시 변경 충돌과 저장 결과 불명확 재시도를 처리한다. 새 업무 메뉴 없음.

## 데이터 적용

`20260912152940_care_learning_assignments.sql`: 이미 적용된 원격 이력과 파일명을 일치시켰다. 신규 배정표·감사표·서버 전용 RPC. 새 표의 RLS 활성화, anon/authenticated 접근 회수, service_role에는 SELECT/INSERT만 허용. 관리자 쓰기·담당 교사 읽기는 RPC에서 활성 계정과 최신 배정을 다시 확인한다. 원래 level_snapshot와 방문 140건·연결 140건 보존. 실제 학생의 레벨을 임의로 넣지 않았다. 이번 웹 배포에서 같은 DB 마이그레이션을 다시 실행하지 않는다.

DB 보안 점검에서 새 표의 정책 없음 정보가 표시되지만 의도한 서버 전용 구조다. 브라우저 역할에는 표·함수 권한이 없으며 서버 서비스 역할만 경유한다. 기존 시스템의 다른 보안 항목은 이번 기능 범위와 별개다.
