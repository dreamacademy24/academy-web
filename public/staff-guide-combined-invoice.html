💰 튜터 결합 인보이스 안내

2026-07-20 신규 기능 · 한 집(예약자)에 튜터 수업이 여러 건일 때, 인보이스를 한 장으로 합쳐서 보여주는 기능입니다.

1. 왜 생겼어요?

  • 한 집에서 아이별·튜터별로 수업을 여러 건 신청하면 (예: 양지나 집 4건) 인보이스가 각각 따로 생겨 헷갈렸어요.
  • 이제 🏠 집 단위 결합으로 한 장에 전부 합산됩니다. 기존 개별 수업 인보이스도 그대로 있어요.

2. 사용 방법

  • 튜터 수업 관리 → 인보이스 탭 → 수업 선택 드롭다운 맨 위 "🏠 집(예약자) 단위 결합" 그룹에서 선택 (예: "🏠 양지나 — 4건 결합")
  • 수업이 2건 이상인 집만 자동으로 나타나요. 1건뿐인 집은 기존 개별 인보이스를 쓰면 됩니다.
  • 인쇄/PDF · 이미지 저장 버튼도 그대로 사용 가능.

3. 화면 읽는 법

  • TOTAL / 납부됨 / 잔액 — 수업 전체 합계에서, 티쳐들이 기록하고 한국 직원이 승인한 납부를 뺀 잔액이 자동 계산돼요. 승인 대기 금액은 괄호로 따로 표시.
  • 수업별 표 — 수강자 / 튜터 / 유형(1:1·1:2, 타임) / 요일 / 회차 / 일단가 / 금액.
  • 달력 — 날짜마다 어느 튜터가 몇 시에 오는지 표시 (예: Cristel · 1:1 · 17:30). 취소된 날은 자동 제외.
  • 납부 내역 — 티쳐가 기록한 수령 건이 날짜·내용·금액으로 나열, ✓=승인됨 / (승인대기)=아직 미승인.

4. 티쳐 납부 기록 흐름 (같이 알아두기)

  • 티쳐: Dream Staff → Tutor Class → 💰 Invoice 탭 → 보라색 "💵 Record Payment Received"에 금액·날짜 입력 → Record
  • 한국 직원: 정산 관리에서 해당 건 승인 → 그때부터 결합 인보이스 "납부됨"에 반영
  • 회차·금액은 출석(Attendance) 기준 자동 계산이라, 출결 기록이 정확해야 인보이스도 정확해요.
⚠️ 잔액이 0이 아닌데 손님이 "다 냈다"고 하면 → 티쳐 기록이 승인 대기 중이거나 누락된 것. 정산 관리에서 승인 여부부터 확인하세요.

5. For Tutors (English)

Combined invoice: In the Invoice tab, the dropdown now has "🏠 Combined by house" — one invoice for all classes of the same family, with TOTAL / PAID / BALANCE. The calendar shows which tutor comes on each date. When you receive payment, record it via 💵 Record Payment Received — it appears on the invoice after Korea staff approval.
