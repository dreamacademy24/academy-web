Student Care & Learning

A step-by-step screen guide for administrators and teachers

Follow the actual screens, select the same buttons and verify the saved result.

The existing directory is shown immediately. Exact visit matches are linked automatically. Find the student and assign a teacher; review only exceptions.

01 · Overview

One student. A separate record for every visit.

Verify student→Link visit→Assign teachers→Continue care

A student keeps one learner record. Each training visit has its own period. A return visit is added without replacing the previous visit.

FeatureCurrent scope
Student reviewThe existing directory appears immediately; exact visits link automatically. Administrators review exceptions.
Visit historyView separate visits with their start and end dates.
Care teamAssign or remove multiple teachers per visit and retain the change history.
Learning experienceTry My Tree House: story, listening, vocabulary, matching, spelling, handwriting and recording.
Still in development

Visit-specific official levels and textbooks, lesson notes, student report publication, child selection, account-based learning sync, recording submission to teachers, feedback and student-linked video reviews are not available yet. Integration with existing class and video-class tools is a later step.

02 · Korean administrators

Find existing students → assign teachers → review exceptions

Sign in → 학생 케어 · 방문 이력 (Student Care)

1

Open the existing student directory

Open Student Care. The existing student directory appears immediately. Records with an exact student ID, booking, name and valid visit dates are linked automatically. Staff do not need to rebuild the directory.

Check the result · The header shows source-record, linked-visit and review counts. Source records may include repeat visits.

2

Search by name and find this visit

Enter the Korean or English name in 학생 이름 검색. Select 담당자 미배정 방문 to show linked visits without an active teacher. Use Previous / Next at the bottom to move through the list.

Check the result · Check the student name and visit start/end dates. Visits marked 자동 연결 (Automatically linked) are ready for teacher assignment.

3

Assign and save the teacher

Use 담당 선생님 추가 → 선생님 선택 (Add teacher → Select teacher). Check the student, period and teacher in the confirmation area, then select 배정 저장 (Save assignment). Use 취소 to cancel.

Check the result · Check for 담당자 변경을 저장했습니다. (Assignment saved) and the teacher name on the visit card. The teacher opens Teacher Hub → My students → Refresh to see the assigned visit.

4

Review only records needing attention

Select 확인 필요한 기록만 (Needs review only). Check whether visit dates, identity/booking information or a booking is missing. Open 확인 필요한 기록 검토 → to review exceptions. Do not merge records by name alone.

Check the result · The student remains visible in the directory before review. Teacher assignment becomes available once the visit is linked.

5

When an exception is verified

For an ID-match candidate, select 학생과 방문 연결하기. Choose a new or verified existing learner under 연결할 학생, enter 수업 시작일 / 수업 종료일, check the identity-and-period confirmation box and select 확인한 학생에 연결 확정. Name-only matches and missing bookings require source review/correction first.

Check the result · Check 연결 완료 (Linked), then Refresh Student Care. Do not manually relink automatically linked records.

Return visits and teacher changes

Verified visits remain separate by period. Existing visits and assignment history are preserved. Different source IDs are not treated as one child based on name alone. To change teachers, add the new teacher and use 배정 해제 → 해제 저장 for the previous teacher. Check 담당자 변경 이력 for the history.

03 · Local teachers

Find your students in My Students

Staff sign-in → Teacher Hub → My Students

  1. Search by student name and check the visit start and end dates.
  2. Check the Care team to see the teachers assigned to the visit.
  3. If a student or visit is missing, ask an administrator to check your assignment. Include the exact student and visit dates.

You can currently view only visits assigned to you. Other visits for the same student and the full student register are not shared automatically. Handover of previous-visit reports is still in development.

Local teachers cannot confirm student links or change assignments. The new Student Care page does not display booking fees, settlement details or parent contact information.

If an assignment is removed or your account is deactivated

Access ends on the next request. Use Refresh when the information appears out of date.

04 · Learning experience

Look, listen, write and speak within a story

Mode selection → 학습모드 (Learning) → 나무집으로 출발

1

Choose Learning

Open mode selection and select the right-hand 학습모드 (Learning) card. Guest is for applications and booking preparation.

Check the result · The DSL-F2 · WEEK 01 unit opens.

2

Start the story

Select 나무집으로 출발 (Start) and then 이야기 속으로 (Enter the story).

Check the result · The story advances from 1/9 to 2/9 and displays the first scene.

3

Listen and select a word

Use the speaker button to hear the dialogue and the house hotspot to progress. Select house or tree in the sentence to open its word activities.

Check the result · The word-activity screen and its activity tabs appear.

4

Hear the word and choose an activity

Select 단어 듣기 to hear the word. Choose a tab: Find the picture, Match, Spelling, Write or Speak.

Check the result · The chosen activity appears. 이야기로 돌아가기 returns to the same story scene.

5

Match words and pictures

Select a word on the left, then its matching picture on the right. Find three pairs, then select 다음 활동 (Next activity).

Check the result · The matched-pair count increases. If incorrect, review the picture and sound and try again.

6

Spelling and handwriting

In 스펠링, type or select letter tiles and press 맞는지 볼까요? (Check). In 써봐요, draw with a finger or pen; use 한 획 지우기 to undo one stroke.

Check the result · Check the spelling feedback. Handwriting is saved on the current device without automatic grading.

7

Record and play back

Select 말해요 → microphone (녹음 시작, Start recording) → allow microphone access → say the word/sentence → 녹음 정지 (Stop). After saving, use playback and optionally 파일로 저장 (Download).

Check the result · Check for 기기에 저장됨 (Saved on device) and the playback controls. Recordings are not sent to a teacher yet.

The entrance offers Guest (applications) and Learning modes. Guest links to the existing application and booking flow. Continue using existing application and booking tools as usual. Do not create dummy payments or applications to check the new features.

  1. Follow My Tree House.

    Tap objects and scenes to move through the story and listen to English dialogue. The current version follows Bobby and Mia with illustrated scenes and scene motion. The full Dreamy-led game redesign is still in development.

  2. Try the word activities.

    Use listening, word finding, matching and spelling, then return to the story. English playback has been slowed for young beginners. Voices vary with the device's English speech settings.

  3. Write and record.

    Use a finger or pen on the handwriting pad. Record a word or sentence and play it back. Allow microphone access when the browser asks.

Recordings are not submitted to teachers yet

Progress, handwriting and recordings are stored in the current browser on this device. They do not sync across accounts or devices. Clearing browser data may remove them. Handwriting and pronunciation are not automatically graded. Avoid unnecessary personal information in recordings.

Official stage labels are DSL-F2, DSL-T1, DR-F1, DR-F2, DR-S and DR-T. The first trial unit is DSL-F2 Week 1.

05 · Troubleshooting

What to do when something goes wrong

IssueWhat to check
Sign-in reminderUse the page's sign-in-again button. The server session may have expired even if an older page is open.
Sign-in service unavailableRetry shortly. If it continues, tell your administrator the time and page URL. Never include your password in messages or screenshots.
Student missingClear the search and filters, then Refresh. Administrators should check the original student directory; teachers should check their assignment for the visit.
Assignment changed messageRefresh and choose again. Another administrator may have saved a change first.
Save result unavailableYou may retry the same save from the current screen. After refreshing, inspect the history before making another change.
No audio or recordingCheck volume, microphone permission and English speech support. Try another supported browser if needed.

06 · First-use checks

Start with a small number of verified students

  • Administrator and local teacher sign-in both work.
  • A verified student can be linked and an actual return visit added without replacing the first visit.
  • A teacher sees assigned visits and cannot see unassigned visits.
  • After removal and Refresh, the visit disappears from the teacher's list.
  • Story, word games, handwriting, recording and playback work.
  • Buttons and fields are usable on a phone.

When reporting an issue, include the URL, device and browser, steps taken, expected result and actual result. Do not include passwords or real students' personal information.
