01 · 한눈에 보기

같은 학생, 방문별로 이어지는 기록

학생 확인→방문 연결→교사 배정→함께 케어

학생은 한 명의 기록으로 관리하고, 연수 방문은 기간마다 구분합니다. 재방문할 때 기존 방문을 덮어쓰지 않고 새로운 방문을 추가합니다.

기능현재 범위
학생 연결 검토기존 명부를 바로 표시하고 정확히 일치하는 방문은 자동 연결합니다. 예외만 관리자가 확인합니다.
방문 이력학생별 연수 시작일·종료일과 별도 방문을 확인합니다.
담당 선생님방문마다 여러 선생님을 배정·해제하고 변경 이력을 남깁니다.
학습 체험My Tree House 이야기, 듣기·단어·매칭·철자·손글씨·녹음을 체험합니다.
아직 준비 중

방문별 공식 레벨·교재 입력, 수업 특이사항, 학생 리포트 발행, 자녀 선택, 계정 간 학습 동기화, 선생님에게 녹음 제출, 피드백·화상 리뷰의 학생별 연결은 아직 사용할 수 없습니다. 기존 수업·화상 기능과 새 케어 기록의 통합은 다음 단계입니다.

02 · 한국인 관리자

기존 학생 찾기 → 교사 배정 → 예외 확인

로그인 → 학생 케어 · 방문 이력

1

기존 학생 목록을 바로 엽니다

학생과 방문 이력을 엽니다. 기존 학생 명부가 바로 표시됩니다. 학생 고유번호·예약·이름·방문 기간이 정확히 일치하면 화면에서 자동 연결을 진행합니다. 직원이 전체 명부를 다시 연결할 필요는 없습니다.

완료 확인 · 기존 명부 건수와 연결된 방문·확인 필요 건수가 보입니다. 명부 건수에는 재방문 항목이 포함될 수 있습니다.

2

이름으로 찾고 이번 방문을 고릅니다

학생 이름 검색에 한글 또는 영어 이름을 입력합니다. 담당자 미배정 방문을 체크하면 연결된 방문 중 활성 담당자가 없는 항목만 보입니다. 페이지 아래 이전 / 다음으로 목록을 넘깁니다.

완료 확인 · 학생 이름과 방문 시작일·종료일을 대조합니다. ‘자동 연결’ 방문에는 바로 교사를 배정할 수 있습니다.

3

담당 선생님을 배정하고 저장합니다

담당 선생님 추가 → 선생님 선택을 누릅니다. 확인 영역에서 학생·기간·선생님을 대조한 뒤 배정 저장을 누릅니다. 잘못 선택했으면 취소합니다.

완료 확인 · ‘담당자 변경을 저장했습니다.’ 메시지와 방문 카드에 선생님 이름이 표시되는지 확인합니다. 선생님은 Teacher Hub → My students → Refresh로 배정된 방문을 확인합니다.

4

확인이 필요한 기록만 검토합니다

확인 필요한 기록만을 체크합니다. ‘방문 기간 확인 필요’, ‘학생·예약 정보 확인 필요’, ‘예약 정보 없음’ 사유를 확인하고 확인 필요한 기록 검토 →로 이동합니다. 이름만 같은 기록을 합치지 않습니다.

완료 확인 · 확인 전에도 학생은 명부에 보입니다. 교사 배정은 방문 정보가 연결된 뒤 가능합니다.

5

예외 기록의 신원·기간을 확인한 경우

‘번호 일치 후보’에서 학생과 방문 연결하기를 누릅니다. 연결할 학생에서 새 학생 기록 또는 확인된 기존 학생을 선택하고, 수업 시작일·수업 종료일을 입력합니다. 학생의 신원과 방문 기간을 확인했습니다.에 체크한 뒤 확인한 학생에 연결 확정을 누릅니다. 이름만 일치하거나 예약 정보가 없는 기록은 원본 자료 확인·수정이 먼저입니다.

완료 확인 · ‘연결 완료’를 확인하고 학생 목록에서 Refresh를 누릅니다. 자동 연결된 기록을 다시 수동 연결할 필요는 없습니다.

재방문과 교사 변경

확인된 같은 학생의 방문은 기간별로 보관합니다. 기존에 연결된 방문과 배정 이력은 덮어쓰지 않습니다. 서로 다른 명부 번호는 이름만으로 같은 아이라고 판단하지 않습니다. 교사를 바꾸면 새 교사를 추가하고 기존 교사에서 ‘배정 해제 → 해제 저장’을 진행합니다. ‘담당자 변경 이력’에서 기록을 확인하세요.

03 · 현지 선생님

My Students에서 담당 학생 확인

직원 계정 로그인 → Teacher Hub → My Students

  1. 학생 이름으로 검색하고 이번 방문 시작일·종료일을 확인합니다.
  2. Care team에서 함께 배정된 선생님을 확인합니다.
  3. 학생이나 방문이 보이지 않으면 관리자에게 정확한 학생과 방문 기간을 알려 배정을 확인해달라고 요청합니다.

현재는 배정받은 방문만 보입니다. 같은 학생의 다른 방문이나 모든 학생 명부가 자동 공개되지는 않습니다. 이전 방문 리포트를 인계받는 기능은 준비 중입니다.

현지 선생님은 학생 연결·담당자 변경을 할 수 없습니다. 새 학생 케어 화면에는 예약 금액·정산·보호자 연락처를 표시하지 않습니다.

배정이 해제되거나 계정이 비활성화된 경우

다음 조회부터 해당 정보에 접근할 수 없습니다. 내용이 오래된 것 같으면 Refresh로 다시 확인해주세요.

04 · 학습 앱 체험

이야기 속에서 보고, 듣고, 쓰고, 말하기

모드 선택 → 학습모드 → 나무집으로 출발

1

학습모드 선택

모드 선택 화면에서 오른쪽 학습모드를 누릅니다. 왼쪽 게스트는 연수 신청·예약 준비용입니다.

완료 확인 · DSL-F2 · WEEK 01 첫 단원이 열립니다.

2

이야기 시작

나무집으로 출발 → 이야기 속으로를 누릅니다.

완료 확인 · 이야기 진행 표시가 1/9에서 2/9로 바뀌며 첫 장면이 나옵니다.

3

대사 듣고 단어 누르기

스피커 버튼으로 대사를 듣고 집 모양 버튼을 눌러 진행합니다. 문장 속 house 또는 tree를 누르면 해당 단어 활동이 열립니다.

완료 확인 · ‘이야기에서 만난 친구’ 화면과 단어 활동 탭이 보입니다.

4

단어 듣고 활동 선택

단어 듣기로 소리를 듣습니다. 상단의 그림 찾기·짝 맞추기·스펠링·써봐요·말해요 중 활동을 선택합니다.

완료 확인 · 선택한 탭의 활동으로 바뀝니다. ‘이야기로 돌아가기’로 같은 이야기 장면에 돌아갑니다.

5

단어와 그림 짝 맞추기

왼쪽 단어 하나를 누르고 오른쪽에서 어울리는 그림을 누릅니다. 세 쌍을 찾은 뒤 다음 활동을 누릅니다.

완료 확인 · 맞힌 짝 수가 올라갑니다. 틀렸다면 그림과 소리를 다시 확인하고 시도합니다.

6

스펠링과 손글씨

스펠링에서 키보드로 입력하거나 글자 타일을 누른 뒤 맞는지 볼까요?를 누릅니다. 써봐요에서는 손가락·펜으로 쓰고, 필요하면 한 획 지우기를 누릅니다.

완료 확인 · 스펠링 결과를 확인합니다. 손글씨는 현재 기기에 자동 저장되며 자동 채점되지 않습니다.

7

내 목소리 녹음하고 다시 듣기

말해요 → 마이크 버튼(녹음 시작) → 브라우저 마이크 허용 → 단어나 문장 말하기 → 녹음 정지 순서로 진행합니다. 저장 후 재생 버튼으로 듣고 필요하면 파일로 저장을 누릅니다.

완료 확인 · ‘기기에 저장됨’과 재생 컨트롤이 보이는지 확인합니다. 아직 교사에게 전송되지는 않습니다.

첫 화면은 ‘게스트(신청용)’와 ‘학습모드’로 나뉩니다. 게스트는 기존 연수 신청·예약 흐름으로 연결됩니다. 기존 신청·예약 업무는 종전과 같이 이용합니다. 새 기능을 확인하기 위한 가짜 결제나 신청은 만들지 마세요.

  1. My Tree House 이야기를 따라갑니다.

    그림 속 사물과 장면을 눌러 진행하고 영어 대사를 들어봅니다. 현재는 바비·미아의 이야기와 장면 움직임을 체험하는 버전입니다. 드림이 중심의 전체 게임형 개편은 아직 준비 중입니다.

  2. 단어 활동을 해봅니다.

    읽기와 듣기, 단어 찾기·매칭·철자 활동을 진행하고 이야기로 돌아갑니다. 초급 학습자를 위해 영어 읽기 속도를 느리게 조정했습니다. 목소리는 기기의 영어 음성 설정에 따라 다를 수 있습니다.

  3. 직접 쓰고 말합니다.

    손가락·펜으로 손글씨를 써보고, 녹음 버튼을 눌러 단어나 문장을 말한 뒤 재생합니다. 브라우저의 마이크 접근 허용이 필요합니다.

녹음은 아직 선생님에게 전송되지 않습니다

학습 기록·손글씨·녹음은 현재 사용하는 기기의 브라우저에 저장됩니다. 다른 기기나 계정으로 자동 동기화되지 않으며, 브라우저 데이터를 지우면 없어질 수 있습니다. 손글씨와 발음은 자동 채점하지 않습니다. 녹음할 때는 불필요한 개인정보를 말하지 않도록 안내해주세요.

공식 학습 단계 표기는 DSL-F2, DSL-T1, DR-F1, DR-F2, DR-S, DR-T를 사용합니다. 첫 체험 단원은 DSL-F2 Week 1입니다.

05 · 문제 해결

이럴 때 이렇게 확인하세요

상황확인 방법
다시 로그인 안내화면의 다시 로그인 버튼을 이용합니다. 이전 화면이 열려 있어도 서버 로그인은 만료됐을 수 있습니다.
로그인 서버 연결 실패잠시 후 재시도합니다. 계속되면 관리자에게 시간과 접속 주소를 알려주세요. 비밀번호를 메시지나 캡처에 넣지 않습니다.
학생이 보이지 않음관리자는 연결 완료 여부를, 선생님은 해당 방문의 배정 여부를 확인합니다. 검색어·필터도 초기화합니다.
배정 정보 변경 안내Refresh로 최신 정보를 읽은 뒤 다시 선택합니다. 다른 관리자가 먼저 변경했을 수 있습니다.
저장 결과 확인 실패같은 화면의 저장 버튼으로 재시도할 수 있습니다. 새로고침했다면 이력부터 확인해 중복 변경을 피합니다.
음성·녹음 안 됨기기 음량, 브라우저 마이크 권한, 영어 음성 지원을 확인합니다. 지원되는 다른 브라우저에서도 확인합니다.

06 · 초기 사용 점검

관리자가 소수 학생부터 확인하세요

  • 관리자와 현지 선생님이 각각 로그인할 수 있다.
  • 확인한 학생을 연결하고, 실제 재방문을 추가해도 이전 방문이 남는다.
  • 선생님에게 배정된 방문만 보이며 다른 방문은 보이지 않는다.
  • 배정 해제 후 Refresh하면 해당 방문이 사라진다.
  • 이야기·단어 게임·손글씨·녹음과 재생이 작동한다.
  • 휴대폰에서도 버튼·입력란을 사용할 수 있다.

문제 제보에는 주소, 사용 기기·브라우저, 누른 순서, 기대한 결과, 실제 결과를 적어주세요. 계정 비밀번호나 실제 학생 개인정보는 포함하지 마세요.
