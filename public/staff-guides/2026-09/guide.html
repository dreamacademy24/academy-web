직원업무 사용 안내

⭐ 이번 개편의 핵심 — 업무에 예약 연결하기
업무를 작성하면서 오른쪽에서 손님 내역을 함께 확인할 수 있습니다. 아래 3번 항목을 꼭 읽어주세요.

2026년 9월 10일 업데이트 · 예약 연결 / 정식 업무 작성 / 손님 내역 함께 보기 / 사진 보기

아래 순서대로 업무를 시작해 주세요. 화면에 등장하는 가족·학생·예약번호는 설명을 위한 예시입니다. 실제 화면에는 본인 계정과 권한에 맞는 정보가 표시됩니다.

1. 내 업무 홈에서 오늘 할 일 확인하기

  1. 상단 내 업무 → 홈으로 이동합니다.
  2. 오늘 마감 · 기한 초과를 눌러 먼저 처리할 업무를 확인합니다. 업무 제목을 누르면 요청 내용과 완료 조건을 볼 수 있습니다.
  3. 확인할 공지는 내용을 읽고 해당 공지의 읽음 확인을 누릅니다. 단순히 열어보는 것과 읽음 확인은 다릅니다.
  4. 내 담당 예약에서 현재 체류 중이거나 입실 예정인 담당 예약으로 이동합니다.

보드 보기: 내 업무의 보드에서 진행 상태별 업무를 볼 수 있습니다. 상단의 공지·댓글·재확인할 업무 펼치기를 누르면 관련 알림이 펼쳐집니다. PC 화면은 좌우 공간을 넓게 사용하도록 정리했습니다.

2. 내 담당 예약과 학생 케어 기록 확인하기

  1. 홈의 내 담당 예약 또는 내 업무 → 손님을 선택합니다.
  2. 이름이나 예약번호로 찾고, 왼쪽 목록에서 예약을 선택합니다. 동명이인·재방문 고객은 예약번호와 체류 기간을 함께 확인합니다.
  3. 선택한 예약의 객실, 학생, 항공 정보와 신청 내역을 확인합니다. 예약 상세 열기로 전체 예약 화면을 볼 수 있습니다.
  4. 공유해야 할 특이사항은 손님 코멘트에 남기고, 날짜별 출석·컨디션·투약 등은 오늘 케어 체크에 기록합니다. 민감한 계정 비밀번호는 코멘트에 적지 마세요.

담당 예약은 예약에 등록된 주담당·케어담당 정보를 기준으로 연결됩니다. 담당 예약이 보이지 않으면 먼저 예약 상세의 담당자 배정을 확인해 주세요. 아래의 ‘업무에 예약 연결’은 예약 담당자를 변경하는 기능이 아닙니다.

⭐ 3. 업무를 작성하고 관련 예약 연결하기 핵심 변경

  1. ＋ 업무 작성 또는 ＋ 업무 추가를 누릅니다. 이제 팝업이 아닌 정식 작성 화면에서 작성합니다.
  2. 업무 제목에는 해야 할 일을 적고, 요청 내용에는 배경·해야 할 일·결과 전달 방법을 적습니다. 빈 내용에서 작성 가이드 넣기를 누르면 작성 틀을 사용할 수 있습니다.
  3. 오른쪽에서 담당자와 기한을 지정합니다. 필요한 경우 긴급·팀공유·비밀을 설정합니다.
  4. 관련 예약 연결에 예약자명이나 예약번호를 두 글자 이상 입력한 뒤 검색합니다. 이름·입실일·예약번호를 확인하고 맞는 예약을 선택합니다.
  5. 요청 내용에 예약 링크가 추가되고, 오른쪽에 손님 내역 함께 보기가 나타납니다. 예약을 확인하며 왼쪽에서 업무 내용을 계속 작성할 수 있습니다.
  6. 완료 조건 · 체크리스트와 필요한 사진·파일을 추가한 뒤 업무 등록을 누릅니다. 등록이 완료되었는지 확인해 주세요.

예시: “입실 가족 항공편 확인 및 픽업 안내” → 담당자 Song → 완료 조건 “항공편 확인”, “픽업팀 전달 후 결과 남기기”. 다른 직원에게 요청하는 경우 본인 이름 대신 실제 담당자를 선택하세요.

두 화면을 따로 쓰고 싶다면: 오른쪽 전체 예약 상세 ↗를 누르면 별도 탭에서 예약 상세가 열립니다. 두 번째 모니터나 브라우저 창으로 옮겨서 함께 볼 수 있습니다. 오른쪽 요약은 조회용이며 예약 수정은 전체 예약 상세에서 진행합니다.

4. 업무 진행·완료와 손님 내역 함께 보기

  1. 업무 제목을 눌러 상세 화면을 엽니다.
  2. 예약이 연결된 업무는 링크 옆의 손님 내역 옆에서 보기를 누릅니다. 오른쪽에서 예약 요약을 확인할 수 있습니다.
  3. 진행 상황 · 결과 보고에 진행한 내용과 필요한 확인사항을 적고 보고 등록을 누릅니다.
  4. 완료 조건이 있으면 실제로 끝낸 항목을 체크합니다. 모든 완료 조건을 체크하면 업무가 완료됩니다. 완료 조건이 없는 업무는 업무 완료를 누릅니다.

일반 업무에는 대표의 별도 승인 단계가 없습니다. 직원과 대표 모두 각자의 업무를 확인해 완료하면 됩니다. 저장된 완료 업무는 진행 목록에서 빠지며 완료 목록에서 다시 확인할 수 있습니다. 결재가 필요한 문서는 별도의 결재 메뉴를 사용합니다.

5. 여러 사진 올리고 크게 보기

  1. 업무 작성·수정 화면의 첨부파일에서 사진을 여러 장 선택합니다.
  2. 큰 JPG·PNG·WebP 사진은 업로드 전에 보기 좋은 크기로 최적화합니다. 기기에 있는 원본은 그대로 남습니다. 원본 업로드가 필요한 경우 이번에는 원본 파일 그대로 업로드를 선택합니다.
  3. 업로드가 끝난 뒤 업무를 저장합니다. 실패한 파일이 있으면 실패 안내를 확인하고 다시 시도하세요.
  4. 업무 상세의 사진을 누르면 크게 볼 수 있습니다. 여러 장이면 이전·다음 버튼이나 방향키로 이동하고 원본 크기로 확인할 수 있습니다.

기존 ZIP 파일은 계속 다운로드할 수 있습니다. ZIP 내부 사진을 자동으로 풀어서 보여주는 기능은 아닙니다. 화면에서 바로 보여줘야 하는 사진은 이미지 파일로 직접 첨부해 주세요. 저장공간·업로드 제한이 무제한으로 바뀐 것은 아닙니다.

6. 주간 체크·달력·결재·의견요청

  • 주간 체크: 요일을 선택해 해당 날짜의 반복 업무를 확인합니다. 손님별 항목이 있으면 해당 손님까지 확인하고 체크합니다. 오늘 항목은 홈의 오늘 체크리스트와 연결됩니다.
  • 달력: 날짜를 선택하면 해당 날짜의 업무와 연결 일정을 상세 목록으로 볼 수 있습니다. 달력에 표시된 요약만 보지 말고 날짜별 목록도 확인하세요.
  • 결재: 실제 승인이 필요한 문서를 상신하고 결과를 확인하는 메뉴입니다. 일반 업무 완료와 구분해 사용합니다.
  • 의견요청: 상단 메뉴로 이동했습니다. 팀에 의견을 요청하거나 기존 요청을 확인할 때 이용합니다.
  • 공지사항: 공지 목록에서 제목을 눌러 읽습니다. 필수 공지는 읽은 뒤 읽음 확인을 눌러주세요.
  • 프로젝트·자료: 여러 업무를 프로젝트로 정리하고, 반복해서 참고할 업무자료는 자료 메뉴에서 확인합니다.

채팅 메뉴와 채팅 기능은 종료했습니다. 업무 관련 진행 내용은 해당 업무의 결과 보고·댓글에, 의견 수렴은 상단 의견요청에 남겨주세요.

7. 저장 실패나 조회 오류가 보일 때

“저장 실패”가 표시되면 완료된 것으로 판단하지 마세요. 작성 내용은 유지한 상태에서 연결을 확인하고 다시 시도합니다. 업로드 중에는 화면을 닫지 마세요. “조회 실패”는 “신청 없음”이나 “예약 없음”과 다른 상태입니다. 오류가 반복되면 사용 중인 메뉴와 오류 문구를 담당자에게 전달해 주세요.
